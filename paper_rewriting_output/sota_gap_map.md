| Work | Core idea | What it prunes/guides well | Gap relative to this draft |
|---|---|---|---|
| Sylvia (Ryan et al., 2023) | Split RTL symbolic execution across independent always blocks and recombine feasible subpaths. | Avoids re-exploring equivalent work across independent blocks/modules. | Leaves redundancy inside one always block largely intact; does not prune branch combinations that converge to the same intra-block symbolic state. |
| SEIF | Builds information-flow verification/search heuristics on top of Sylvia-style RTL symbolic execution. | Better targets security-relevant exploration objectives. | Changes verification focus and search priority, not the redundancy source caused by sequential branch interactions inside combinational blocks. |
| RTL-ConTest / directed RTL symbolic testing | Generates targeted RTL tests with CFG-aware symbolic/concolic exploration. | Reaches target behaviors faster than unguided exploration. | Target direction is not the same as semantic path collapsing; redundant intra-block paths may still be explored if they satisfy the same target trajectory. |
| LLM-assisted path exploration for RTL verification (Tan et al., 2025) | Uses LLM guidance to steer path exploration toward promising behaviors. | Reduces search effort through higher-level path selection. | Guidance is external and heuristic; it does not exploit RTL dataflow to prove that different branch histories are state-equivalent and safely prunable. |
| Hypothesis row: dataflow-guided pruning draft | Analyze forward data dependencies in combinational always blocks during RTL symbolic execution. | Prunes branch histories whose differing decisions cannot affect final outputs/store for the current block. | Claimed novelty is the post-Sylvia, intra-block pruning unit: redundant paths are removed because they are semantically non-distinguishing, not merely lower priority. |

Gap summary: Prior RTL symbolic-execution work mainly attacks inter-block recomputation, target selection, or security/property guidance.
Gap summary: The draft’s defensible niche is narrower and sharper: pruning redundant intra-block combinational paths that reach the same symbolic effect after sequential assignment propagation.
Gap summary: The paper should therefore frame its contribution as complementary to Sylvia, replacing “general path-explosion reduction” claims with “state-equivalence pruning within a single always block.”
